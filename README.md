# LexComboGen(Lexicographical Combination Generator):

## 📖 About This Project

This repository explores and implements new algorithms for the generation of combinations in lexicographical order. Generating combinations efficiently is a fundamental problem in computer science, combinatorial mathematics, and optimization. 

To provide a comprehensive analysis, this project includes two distinct approaches:
* **Parallel Architecture:** High-performance implementations designed to accelerate combination generation using parallel processing techniques.
* **Serial Architecture:** Sequential algorithms and baseline codes, integrated alongside benchmark instances to validate performance and accuracy.

By combining these architectures, this repository serves as a framework for testing, comparing, and utilizing advanced lexicographical combination generation methods.

## 📂 Project Structure

The project is divided into two main modules:

*   **`parallel`**: Contains the Parallel MEBKE Architecture codebase.
*   **`serial`**: Contains the serial codes instances.
